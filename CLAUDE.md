# YOU SPENT: working agreement

- Read `docs/DECISIONS.md` and `docs/ARCHITECTURE.md` before changing code.
- Reply to the owner in Russian, short, phone-readable. Mark claims Known / Hypothesis / Unknown.
- No personal data in the repo: no real amounts, names, tokens, deployment URLs or spreadsheet ids. Tests use invented data. Private files live in gitignored `private/`.

## Git
1. Work in your own branch and open a PR.
2. Check that tests are green.
3. Ask the owner one question: "Мержить?".
4. On "да", merge the PR into main yourself (merge_pull_request). If it is a draft, mark it ready first. Never merge without that "да", and never ask the owner to press Merge.
5. Then check that the deploy went out and report briefly what changed.
